# Electronics Network API

Веб-приложение на Django для управления иерархической сетью по продаже электроники.  
Включает административную панель, веб-интерфейс с Bootstrap, а также REST API с документацией.

---

## 📦 Возможности

### 📁 Иерархия сети

- Три уровня участников сети:
  - Завод
  - Розничная сеть
  - Индивидуальный предприниматель
- Каждый участник может иметь поставщика (необязательно предыдущий по иерархии)
- Уровень определяется отношениями, а не названием

### 🧾 Участник сети содержит:
- Название
- Контакты:
  - Email
  - Страна, город, улица, номер дома
- Продукты:
  - Название, модель, дата выхода на рынок
- Поставщик
- Задолженность перед поставщиком (decimal, точность до копеек)
- Дата создания (автоматически)

## 🔧 Установка и запуск

- git clone <https://github.com/AndreyPetrovichTarasov/attestation/tree/develop>
- cd <attestation>
- poetry install
- python manage.py migrate
- python manage.py createsuperuser
- python manage.py runserver

## 🛠 Админ-панель

Доступна по адресу: http://127.0.0.1:8000/admin/

✅ Возможности:
Просмотр всех узлов сети и продуктов

Фильтр по городу

Поиск по названию

Ссылка на поставщика на странице узла

Admin Action: очистка задолженности перед поставщиком

## 🌐 Веб-интерфейс (Bootstrap)

Доступен по адресу: http://127.0.0.1:8000/

Список узлов с поставщиком и долгом

Детальная страница узла

Создание нового узла

Создание продуктов для узла (с выпадающим выбором)

Выбор даты через календарь

## 🔌 API (DRF)

🔐 Доступ:
Только для авторизованных и активных сотрудников (is_staff=True, is_active=True)
Основной эндпоинт: /api/nodes/

Поддерживает:

GET /api/nodes/ — список узлов

POST /api/nodes/ — создание

GET /api/nodes/<id>/ — просмотр узла

PUT/PATCH /api/nodes/<id>/ — обновление (без возможности изменить debt)

DELETE /api/nodes/<id>/ — удаление

Поиск по стране (например: /api/nodes/?search=Россия)

## ✅ Особенности реализации

Поле debt недоступно для изменения через API

Проверка авторизации через DRF-права

Подключён drf-spectacular для автогенерации OpenAPI документации

Поддержка фильтрации, поиска и кастомных админ-действий

Чистая верстка с Bootstrap 5

Обработка даты через HTML5 <input type="date">

## 🧑‍💻 Авторизация

Создайте суперпользователя:

bash: python manage.py createsuperuser

Войдите в админку и создайте обычного пользователя

Назначьте ему is_staff=True, is_active=True — тогда он сможет работать с API
